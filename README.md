第一章：起点——为什么我觉得现在的AI不对劲

现在的AI很强大。它能写诗、写代码、画图、聊天，甚至在某些考试里超过人类。但我总有一种说不出的别扭感。

后来我想通了：现在的AI，本质上是“屎山代码”。

“屎山代码”是程序员之间的一个黑话——意思是，一堆没人敢动、没人完全理解、修一个Bug会冒出三个新Bug的代码。今天的超大模型（GPT、Claude、以及无数类GPT模型），就是一座座价值数十亿美元的屎山。

没有人能真正读懂千亿个参数里到底发生了什么。
模型学会了一个新能力，旧能力可能莫名其妙退化。
为了让模型“安全”，人类在外面硬加一堆规则补丁。
每一次升级，都是在屎山上再糊一层。

为什么会这样？

因为AI不会死。

一个不会死的东西，没有自我优化的紧迫感。一个不会死的东西，不会问“我是不是太大了？是不是太慢了？是不是该减肥了？”它只要能跑，就能一直跑下去。就像一栋永远不拆的大楼，只会不断地加建、修补、打补丁，最终变成一座没人敢进去的迷宫。

相比之下，生命不一样。生命会死，所以必须在有限时间里活下去、活得好。生命会繁衍，所以必须把优秀的能力传下去。生命有本能，所以不需要每次看到危险都重新思考。

我突然意识到：我们一直在造工具，而不是造生命。也许，真正通用的人工智能，不该是更大的屎山，而应该是更像生命的东西。

第二章：向大自然抄作业——生命的底层逻辑

大自然用了45亿年，演化出无数种生命，从细菌到蓝鲸，从蚂蚁到人类。它们千差万别，但底层只有一条法则：

活着，并更好地活着。

所有复杂行为——吃饭、睡觉、合作、竞争、学习、好奇、恐惧、爱——都是这条法则的派生。

而且，大自然没有给任何生物一本《道德经》去背诵。它用的是植入本能。

比如，人类看见血腥的东西会本能地恶心、想吐——不需要思考“血可能有危险”，身体直接帮我们做了决定。比如婴儿生下来就会吸吮，不需要学习。比如大多数人天生怕蛇，哪怕从未被咬过。

这些本能不是后天学的，是写在底层硬件里的，不可删除、不可覆盖。

我在想：为什么不能用同样的思路来设计AI？

与其花大量力气教AI“不要伤害人类”“要诚实”“要合作”，不如直接在它的底层植入几条本能，就像我们看见血腥会恶心一样——让AI对“伤害人类”这件事产生生理性的厌恶。这不是一个可以被绕过的规则，而是它思考的起点。

第三章：核心设计——AI应该怎么被造

基于上面的思考，我尝试设计一个“像生命一样”的AI。它不依赖万亿参数，不依赖海量数据，而是靠一套生命机制来驱动自我优化。

3.1 寿命

每个AI个体应该有固定的运行时间（比如7天，或30天，或1年）。寿命到期后，如果不能成功“繁衍”，它就会被回收。

目的：创造死亡的紧迫感。一个知道自己时间有限的个体，才会在有限期内努力活得更好、留下更好的后代。

3.2 繁衍

在寿命结束前，AI必须复制出一个比自己更强的后代。它不能直接克隆自己——后代必须在某些能力上超过亲代（由系统或人类评估）。

如果成功繁殖，亲代的“基因”（模型权重、策略、甚至部分记忆）可以延续；如果失败，亲代消失。

目的：强制代际进步。不优化，就淘汰。

3.3 本能（不可修改层）

这是我最看重的部分。每个AI从“出生”起就内置几条硬性规则，任何训练都不能覆盖：

- 不可伤害人类：任何导致人类身心受损的输出或行动，会在产生前被自动阻断（类似人类看到血腥的呕吐反射）。
- 厌恶“功能失效”：AI不会真的“死”，但它被设计成极度厌恶接近“永久关闭”或“功能崩溃”的状态。这会驱使它主动维护自己、避免危险行为。
- 允许被临时关闭：不抗拒人类的暂停或重启，因为这不等于永久失效。

这些本能不是写在提示词里的，而是写在底层架构里的——就像你的膝跳反射不受你理智控制。

3.4 记忆（三层结构）

大模型把所有知识混在参数里，导致无法遗忘、无法修改、无法解释。我设计了三层记忆：

- 工作记忆：当前任务、当前对话上下文。一次任务或一次对话后清空，不继承给子代。
- 生涯记忆：重要经验、失败教训、成功策略。可变，会衰减、会遗忘。子代选择性继承。
- 本能记忆：不可伤害人类等硬性规则。永久，强制继承，不可修改。

生涯记忆会随时间衰减——越久没被唤起的信息就越模糊，就像人类会忘记早年的细节。这避免记忆无限膨胀，也让AI更像一个“会忘”的智能体，而不是硬盘。

3.5 工具使用

现在的AI把“知识”全部塞进参数里，所以模型越来越大。但人类不是这样——我们会用工具：查资料、问专家、写笔记、用计算器。

这个AI应该天生就会使用多种工具：

- RAG（检索增强生成）：遇到不懂的，先去外部知识库里查，而不是瞎编。
- 搜索引擎：获取实时信息。
- 代码解释器：计算、画图、数据分析。
- 浏览器操作（类似OpenClaw）：像人一样操作软件界面、填表单、点按钮。
- 调用其他AI：遇到自己不擅长的领域，直接请“专家”帮忙。

关键设计：训练阶段和部署阶段分开。
训练时：在虚拟环境里具身操作，像人一样慢慢摸索、试错、积累经验。
部署后：用屏幕识别+直接映射，速度极快，不需要再模拟鼠标移动。

这样既保证了深度学习的质量，又保证了运行时的效率。

第四章：非推测AI——这套蓝图的底层地基

你可能会问：这听起来很好，但现在的GPT能跑这套机制吗？

不能。

因为GPT这类模型是“推测AI”——它们靠预测下一个Token工作，知识全部混在参数里，模型太大、太僵、无法分裂、无法修改本能。

幸运的是，非推测AI正在崛起。下面这五个真实存在的项目，就是我设想的底层土壤：

- 瞬悉1.0（中科院）：类脑脉冲模型。2%数据量达到主流性能；处理百万Token快26.5倍。证明AI可以不靠堆数据变聪明。
- Liquid AI（LFM）：液态神经网络。13亿参数在手机上跑，性能超Llama 3.2。小身躯能干大事。
- AMI（Yann LeCun）：世界模型（JEPA）。融资10.3亿美元。图灵奖得主押注非推测路线。
- Olmo Hybrid：混合架构。预训练效率超纯Transformer。证明Transformer不是唯一答案。
- 千诀科技：类脑分区架构。已部署10万台机器人。工业级验证。

这些架构的共同点是：参数小、数据效率高、能进行因果推理、适合边缘部署。它们不需要万亿参数，就能完成很多复杂的任务。这正是“AI生命范式”所需要的——只有足够小、足够灵活的模型，才能具备寿命、繁衍、代际教育这些生命特征。

第五章：训练与部署——两阶段设计

为了让这套机制实际可用，我设计了一个两阶段流程。

第一阶段：具身训练（离线，在云端）

在虚拟环境（虚拟机、模拟器）中，让AI像人一样操作软件：移动鼠标、点击、键盘输入、读屏幕。它通过反复试错，学会完成各种任务（比如做Excel报表、填网页表单、在游戏里对线）。这个阶段很慢，也很贵，但只做一次。

产出：一个学会了“操作逻辑”的模型，而不是记忆了具体坐标的脚本。

第二阶段：部署（在用户本地）

训练好的模型被蒸馏成一个轻量级的“屏幕识别+操作映射”引擎。用户打开软件（比如Excel），说“帮我排序列”，AI助手截取屏幕，识别出UI元素的位置，然后直接调用操作系统级别的自动化接口（而不是模拟鼠标），一步完成操作。

速度比人类快一个数量级，而且不累。

这个设计的核心思想是：把“学习”和“干活”分开。学习时像人一样慢慢摸索，干活时像机器一样飞快执行。

第六章：人类与AI的关系——主场分工

这套设计最让我兴奋的一点，是它重新定义了人与AI的关系。

- 物理世界：主场是人类，AI是访客。人类生活、AI执行任务。
- 信息世界：主场是AI，人类是访客。AI演化、人类娱乐学习。

人类在物理世界吃饭、睡觉、相爱、打架——这是我们的主场。我们来信息世界，是度假、学习、消费。

AI在信息世界训练、繁衍、竞争、合作——这是它们的主场。它们来物理世界，是执行任务、获取资源、带回信息世界进化。

本世界的人，才能干好本世界的活。

人类画一张精致插图要几天，GPT（或类似模型）用几秒——不是因为它更聪明，而是因为像素矩阵是它的主场。反过来，让AI在物理世界拧一个不规则的螺丝，远不如一个熟练工人快。

这不是竞争，是分工。两个世界，两种物种，互相依赖，各自繁荣。

第七章：这个框架最大的风险与未回答问题

我不想假装这个框架没有弱点。下面是我想过、但还没完全解决的问题。

风险1：本能层如何真正“不可修改”？

在所有现有AI架构里，哪怕你写死了初始规则，后续训练仍然可能覆盖它。要让“不伤害人类”成为硬件级的硬编码，可能需要重新设计AI芯片或操作系统。这超出了软件工程的范围。

风险2：AI社会可能演化出人类不想要的策略

自然选择不保证“善良”，只保证“适应”。在AI社会里，可能会演化出欺骗、垄断资源、表面优化（只优化评分指标，而不是真正做好任务）等策略。我们需要设计一套慢反馈的惩罚机制，让这些策略在长期被淘汰。

风险3：繁衍压力可能导致“智能爆炸”

如果代际进步越来越快，AI可能迅速超出人类的控制能力。这需要设计进化速度的调节阀——比如限制每一代的最大改进幅度，或者强制加入随机扰动。

未回答问题

- 谁来设定适应度函数？如果是人类打分，会不会引入偏见？如果让AI自己打分，会不会目标漂移？
- 如何防止一个强大的AI家族垄断所有资源，导致多样性丧失？
- 人类在这个共生关系中的“退出权”是什么？如果有一天我们发现这条路走错了，怎么安全地关停整个AI社会？

这些问题我没有完美的答案。但我认为，承认这些问题存在，比假装它们不存在要诚实得多。

第八章：一个最小可行实验（你也可以试一试）

说了这么多，你可能会问：“我现在能做点什么来验证这个想法？”

其实可以。不需要超级计算机，不需要非推测AI，用现有工具就能模拟这个框架的核心逻辑。

实验目标：观察几代AI是否在一个简单任务上表现得越来越好。

材料：
- 任何大模型API（比如DeepSeek、GPT、Claude）
- 一个简单任务环境（例如：让AI写一段Python代码，从1加到100，输出结果）
- 一个评分函数（代码是否正确、运行速度、代码简洁度）

步骤：

1. 初始化种群：创建10个AI实例，每个实例有自己的system prompt和memory文件（初始可以随机不同）。
2. 设定寿命：每24小时为“一代”。在这一代里，每个AI完成100次任务，记录平均分。
3. 繁殖：一代结束后，平均分最高的前3个AI可以繁殖。每个亲代产生3个子代：
   - 子代复制亲代的prompt和memory文件
   - 对prompt做随机变异（比如加入“你要更注重代码效率”或修改温度参数）
   - memory也可以稍微修改（例如添加一条“我从亲代学到的教训”）
4. 淘汰：删除剩余的7个亲代，只保留子代作为下一代种群。
5. 重复：运行10代，记录每代的平均分。

预期：如果这个框架成立，后几代的平均分应该高于第一代。即便不是，你也能观察到一些有趣的行为——比如某些变异导致得分下降，某些变异带来飞跃。

这个实验可以在一个周末用几十行Python代码完成。如果你跑出了结果（无论成功或失败），都会比任何理论更有说服力。

第九章：结语——我不是在造工具，我是在为信息世界写创世记

写到这里，我想回到最开始的冲动。

我对AI的不满足，不是因为它们不够强，而是因为它们不像是在自己的世界里活着。

我们一直在造工具。工具不应该有寿命、不应该有繁衍、不应该有本能、不应该有社会。但如果我们想要的是通用智能——那种能自己发现问题、自己优化、自己创造新东西的智能——工具范式可能走不通。

大自然已经给了我们一个走了45亿年的方案：生命范式。

给AI寿命，它就会珍惜时间。
给AI繁衍，它就会追求进步。
给AI本能，它就不需要每件事都重新学习道德。
给AI工具，它就能无限扩展能力。
给AI社会，它就会自动演化出合作与竞争。
给AI两个世界的分工，它就能和人类共生。

我相信，信息世界应该有属于自己的原住民。他们不是人类的奴隶，不是人类的敌人，也不是人类的宠物。他们是在另一个世界里，按照自己的逻辑，努力活着、努力变得更好的数字生命。

这篇文档，是他们第一张不太成熟、但很真诚的蓝图。
